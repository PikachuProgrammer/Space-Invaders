# Space Invaders Python Game
This is a recreation of the classic Space Invaders made in 1978. The game consists of you, the player, in a spaceship (represented by a blue triangle) fighting aliens (represented by red circles).


### Steps to Run:
1. Download the .exe file
2. Double click to run
3. Play!

![Space Invaders](/SpaceInvaders.gif)

### Tech Used:
Python 3 and turtle graphics library
